# Branding Landing Page - Eva Pérez

This project is a branding landing page for Eva Pérez, a Spa Consultant & Wellness Expert. The website is designed to showcase her services, expertise, and success stories.

## Features

The website consists of five main pages:

- **Home:** An overview of Eva Pérez's services and value proposition.
- **About Me:** A detailed description of her philosophy, and areas of expertise.
- **Success Stories:** Testimonials and case studies from previous clients.
- **Services:** A breakdown of the services offered, including Wellness Operations, Revenue Optimization, and Executive Wellness.
- **Contact:** A form for potential clients to get in touch.

## Technologies Used

- **HTML5:** The core markup language for the website's structure.
- **Tailwind CSS:** A utility-first CSS framework for styling the website.

## File Structure

```
.
├── about.html
├── contact.html
├── index.html
├── services.html
└── success-stories.html
```

## How to View

To view the website, simply open the `index.html` file in your web browser. You can also serve the files locally using a simple HTTP server. For example, using Python:

```bash
python -m http.server
```

Then, open your web browser and navigate to `http://localhost:8000`.
